A status or attribute mark. Chips are never buttons — nothing here is tappable.

```jsx
<Chip variant="solid">● LIVE</Chip>
<Chip variant="outline">LOCKDOWN</Chip>
<Chip variant="frame">OUTDOOR</Chip>
```

- `solid` is reserved for right-now activity on a court row. Include the `●`.
- `outline` chips wrap in an 8px-gap row for peer-vouched badges.
- `frame` sits in a metadata row next to plain mono text.
