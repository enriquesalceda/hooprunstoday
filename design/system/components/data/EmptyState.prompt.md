Every empty section in the product is one of these — same dashed `#6f6f6a` frame the game log uses for an unverified score, because "not yet" is the same idea as "not confirmed".

```jsx
<EmptyState label="NO GAMES LOGGED" meta="LOG A SCORE TO OPEN YOUR RECORD" />
<EmptyState label="NO BADGES YET" center />
<EmptyState label="NO LEAGUE TEAM LINKED" meta="LINK ONE IN SETTINGS" />
```

Never hide the section, never draw an illustration, never use color. State what's absent and what fills it.
