Plain hairline-divided list — no border around the group, no bullets.

```jsx
<RosterRow name="NEWTOWN OUTLAWS" meta="DIV II · ACTIVE" />
<RosterRow name="@a_cross" meta="NOT VOTED" muted />
```

As a voter roll, `muted` marks who still owes a vote — the viewer's own row (`@YOU`) should be in the list too, so eligibility is never a mystery.
